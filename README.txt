# Guía Verde — Página web de plantas

## Archivos
- index.html: estructura de la página.
- style.css: diseño y versión para celular.
- script.js: datos de las 7 plantas e interacción.

## Cómo probarla
1. Abre `index.html` en Chrome o Edge.
2. Haz clic en cualquiera de las plantas.
3. Para publicarla, sube estos tres archivos a un servicio de hosting estático como GitHub Pages, Netlify o Vercel.
4. Una vez publicada, copia la dirección pública y genera un código QR que apunte a esa dirección.

## Importante
La información de cultivo es orientativa. El tiempo de crecimiento y las necesidades pueden cambiar según variedad, clima, estación, maceta y condiciones de cultivo.
